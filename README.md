
# 🎮 Connect Four Game in C

## 📌 About the Project

A console-based Connect Four game developed in C as part of my Computer Science studies.

This project demonstrates programming fundamentals, two-dimensional arrays, game logic, and basic AI decision-making.

## ✨ Features

- Player vs. Player mode
- Player vs. Computer mode
- Three AI difficulty levels: Easy, Medium, and Hard
- Horizontal, vertical, and diagonal win detection
- Colorful console interface
- Game statistics tracking wins and draws
- Interactive menu system

## 🛠️ Technologies Used

- C Programming Language
- Microsoft Visual Studio
- Windows Console
- Two-dimensional arrays
- Functions and conditional statements

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Project17.sln` in Microsoft Visual Studio.
3. Build the project.
4. Run the program.
5. Choose a game mode from the menu.
6. Follow the on-screen instructions to play.

**Note:** This project is designed for Windows.

## 🎯 Game Modes

### Player vs. Player
Two players take turns placing discs on the board.

### Player vs. Computer
Play against the computer with three difficulty levels:

- **Easy:** Random moves.
- **Medium:** Detects winning moves and blocks the opponent.
- **Hard:** Uses defensive strategies and prioritizes central columns.
